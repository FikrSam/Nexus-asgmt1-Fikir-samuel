# Week 1 Reflection

## Week 1 Reflection

This week, I learned about the tools that are used in frontend development and why they are important.

I learned about Visual Studio Code and some of the extensions that can make coding easier, such as Prettier, ESLint, Live Server, and GitLens. I also learned that using these tools can help keep code organized and reduce mistakes.

I was also introduced to the Command Line Interface (CLI). I learned a few basic commands for navigating folders and creating directories. Although I still need more practice, I can see why the terminal is an important tool for developers.

Another thing I learned was the purpose of Node.js and npm. I learned that Node.js allows JavaScript to run outside the browser, while npm is used to install and manage packages needed for a project.

We also learned about browser Developer Tools. I found it interesting that they can be used to inspect web pages, test JavaScript, and help find and fix problems while developing websites.

The second part of the week focused on Git and GitHub. I learned that Git is used to track changes in a project, while GitHub allows developers to store and share their code online. I also learned the basic Git workflow and practiced commands like `git init`, `git status`, `git add`, `git commit`, `git push`, and `git pull`.

Finally, I learned that projects should include a `README.md` file to explain what the project is about and a `.gitignore` file to prevent unnecessary files from being uploaded.

Overall, this week gave me a good introduction to the tools used in frontend development, and I look forward to learning more as the course continues.
