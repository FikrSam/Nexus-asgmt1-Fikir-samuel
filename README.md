# Week 1 Learning Reflection

## Introduction to Frontend Development

Frontend development is the part of web development that focuses on what users see and interact with on a website. It involves creating web pages that are easy to use and visually appealing. Frontend developers use tools and technologies to build the user interface of websites.

## How the Web Works

I learned that when we visit a website, a lot of things happen behind the scenes. When we type a website address into a browser, the browser sends a request over the internet to find that website. The website then sends back the information needed, and the browser displays it so we can see and use it.

## The Client-Server Model

The client-server model is how users and websites communicate. The client is the device or browser that requests information, while the server is the computer that stores the website and sends the requested information back to the client.

## The Request-Response Cycle

The request-response cycle is the process of communication between the client and the server. First, the client sends a request for a web page or other information. Then, the server processes the request and sends a response back. Finally, the browser displays the response to the user.

## The Role of Browsers

A browser is the application we use to access websites, such as Google Chrome, Microsoft Edge, or Firefox. The browser sends requests to web servers, receives the responses, and displays web pages so users can interact with them.

## The Role of Web Servers

A web server stores website files and responds to requests from browsers. When a browser asks for a webpage, the web server finds the requested files and sends them back to the browser.

## Tools I Learned About

This week, I also learned about some of the tools used in frontend development:

- **Visual Studio Code** is a code editor used to write and manage code.
- **The Command Line (CLI)** is used to navigate folders and run commands.
- **Node.js** allows JavaScript to run outside the browser.
- **npm** helps install and manage project packages.
- **Browser Developer Tools** help inspect web pages and find errors.
- **Git** tracks changes made to a project.
- **GitHub** stores projects online and makes it easier to share and collaborate.
- I also learned some basic Git commands, including `git init`, `git status`, `git add`, `git commit`, `git push`, and `git pull`.

I also learned how websites communicate through the client-server model and the request-response cycle. Learning about Git and GitHub showed me how developers keep track of their work and share projects.
